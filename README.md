## About the Project

This system helps users organize personal tasks in one simple dashboard. Users can create tasks, update their information, change their status, and remove tasks that are no longer needed.

Each task contains a task name, optional description, status, and due date.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
  - Pending
  - Completed

## Laravel Process

The project follows the Laravel workflow:

**Route → Controller → Model → Database → Blade View**

Routes receive the request, the controller handles the task operation, the model communicates with MySQL, and Blade displays the result to the user.

## Main Task Fields

- ID
- Task Name
- Description
- Status
- Due Date
